# 生成通知与音效（st-gen-notify）

SillyTavern 扩展：AI 生成完成/失败时弹系统通知，并支持自定义完成音效。

## 功能

### 一、完成音效（所有人可用）

替换酒馆生成完成时「叮」的一声：

- **11 款预置音效**（Mixkit 免费授权，随扩展分发）：正向提示、欢快铃铛、魔法铃声、经典铃铛、简短确认、魔法木琴、答对奖励、门铃、界面启动、科幻确认、舒缓笛声
- **点选即生效并自动试听**，选中的高亮
- **自定义上传**：mp3 / wav / ogg / m4a / aac / flac，4MB 以内，只存本机浏览器（IndexedDB），不进设置文件
- **音量可调**：覆盖酒馆写死的 0.8

### 二、系统通知（需本机通知服务）

生成完成或失败时，向 `POST /notify` 发送通知，经反向代理转发到本机的 macOS 通知服务，在屏幕右上角弹系统通知：

- 页面在后台也能提醒，不依赖浏览器通知权限
- **失败通知带完整详情**：状态码、错误码（如 `VERTEX_UPSTREAM_FAILED`）、原因、请求 URL、原始返回——点击通知回到酒馆，在连接监视器里展开查看
- 通知服务不可用时静默跳过，不影响任何功能（音效部分不受影响）

> 注意：通知部分依赖你自己的本机通知服务（监听 127.0.0.1:9180 的 macOS App + 反代 `/notify` 路由）。没有这套服务的环境下，通知不会弹出但也不会报错；音效功能完整可用。

## 安装

1. 下载本仓库（解压到 `public/scripts/extensions/third-party/st-gen-notify`），
   或在扩展管理里用 `https://github.com/Silentforfar/st-gen-notify` 安装
2. 启用扩展，在扩展设置里找到「生成通知与音效」
